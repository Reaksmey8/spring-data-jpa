1. The 6-Step Coding Order (លំដាប់លំដោយពេលសរសេរកូដ)

ពេលបង្កើត Feature ថ្មី ត្រូវសរសេរតាមលំដាប់នេះជានិច្ច៖

  1. Domain Entity: កំណត់ Table ក្នុង Database (ឧ. Product.java)
  2. Repository: Interface extends JpaRepository
  3. DTOs: បង្កើត Request និង Response Records
  4. Service Interface: កំណត់ឈ្មោះ Methods
  5. Service Implementation: សរសេរ Business Logic & Save to DB
  6. Controller: បង្កើត REST Endpoints (@GetMapping, @PostMapping, etc.)

2. The 5 Core Layers Explained (ស្រទាប់ទាំង ៥ នៃស្ថាបត្យកម្ម)

Layer Package តួនាទីសំខាន់ (Role)
Domain domain ជា Blueprint បង្កើត PostgreSQL Table ដោយស្វ័យប្រវត្ត
Repository repository ជួយ execute SQL Queries ដោយស្វ័យប្រវត្ត (CRUD)
DTO dto ការពារទិន្នន័យ (Data Security) សម្រាប់ទទួល និងបោះទិន្នន័យទៅ Client
Service service ខួរក្បាលនៃប្រព័ន្ធ (Business Logic, Validation, DTO Mapping)
Controller controller អ្នកទទួលភ្ញៀវ — ទទួល HTTP Request និងបោះ JSON Response
Exception exception ចាប់ Error ទូទាំងប្រព័ន្ធ ហើយរៀបចំ Response ស្អាត

3. The Essential Annotations Cheat Sheet (កម្រង Annotations សំខាន់ៗ)

Annotation កន្លែងប្រើ អត្ថន័យ និងតួនាទី
@Entity domain ប្រាប់ Spring ថា class នេះជា Database Table
@Id domain កំណត់ Primary Key
@GeneratedValue(IDENTITY) domain Auto-increment លេខកើនស្វ័យប្រវត្ត (1, 2, 3...)
@RequiredArgsConstructor controller / service Lombok បង្កើត Constructor សម្រាប់ Inject final fields
@RestController controller ប្រាប់ថា class ជា Controller និង return JSON ស្វ័យប្រវត្ត
@RequestMapping controller Base URL (ឧទាហរណ៍ /api/v1/products)
@PathVariable controller ចាប់យកតម្លៃពី URL Path (ឧ. /products/{code})
@RequestParam controller ចាប់យក Query Param (ឧ. ?pageNumber=0&pageSize=5)
@RequestBody controller បម្លែង JSON Body ពី Client មកជា Java Object
@Valid controller បញ្ជាឲ្យ Spring ដំណើរការ Bean Validation
@RestControllerAdvice exception Global Exception Handler សម្រាប់ចាប់ Error ទូទាំង App

5. Spring Security Master Guide (មេរៀនសង្ខេប Spring Security ពេញលេញ)

⚠️ ចំណុចគ្រឹះដែលត្រូវចាំ៖
• Authentication ("Who are you?"): ផ្ទៀងផ្ទាត់ Username & Password (ខុសធ្លាក់ 401 Unauthorized)
• Authorization ("What can you do?"): ត្រួតពិនិត្យសិទ្ធិ Role (គ្មានសិទ្ធិធ្លាក់ 403 Forbidden)

A. Request Flow ពេល Client ហៅ Basic Auth:

  1. Client ផ្ញើ Request ជាមួយ Header Authorization: Basic ...
  2. SecurityFilterChain ចាប់យក Request បញ្ជូនទៅ DaoAuthenticationProvider
  3. DaoAuthenticationProvider ហៅ UserDetailServiceImpl.loadUserByUsername()
  4. UserRepository ទាញយក User Entity ពី PostgreSQL Database
  5. BCryptPasswordEncoder ផ្ទៀងផ្ទាត់ Raw Password ជាមួយ BCrypt Hash ក្នុង DB
  6. បើត្រូវគ្នា ➡️ រក្សាទុកក្នុង SecurityContextHolder រួចអនុញ្ញាតឱ្យចូលដល់ UserController
  7. ក្នុង Controller ប្រើ (User) auth.getPrincipal() ដើម្បីទាញយកទិន្នន័យ User

B. លំដាប់លំដោយ ៧ ជំហានពេលសរសេរកូដ (Coding Workflow):

1. PasswordEncoderConfig.java ➡️ បង្កើត @Bean PasswordEncoder (return new BCryptPasswordEncoder())
2. Role.java ➡️ implements GrantedAuthority (return "ROLE_" + this.name)
3. User.java ➡️ implements UserDetails (return this.userName, this.encryptedPassword, this.roles)
4. UserRepository.java ➡️ Method findByUserNameOrEmail(...)
5. UserDetailServiceImpl.java ➡️ @Service + implements UserDetailsService
6. SecurityConfig.java ➡️ Config DaoAuthenticationProvider & SecurityFilterChain
7. UserResponse.java & UserController.java ➡️ DTO ជាមួយ @Builder និង Endpoint @GetMapping("/me")

C. កម្រង Annotations & Classes សំខាន់ៗបំផុត (Cheat Sheet):

ឈ្មោះ (Name) តួនាទី (Responsibility)
@EnableWebSecurity បើកដំណើរការ Web Security របស់ Spring Boot
PasswordEncoder Interface សម្រាប់ Hash និងផ្ទៀងផ្ទាត់ Password (BCryptPasswordEncoder)
UserDetails Interface តំណាងឱ្យទិន្នន័យ User របស់ Spring Security (User.java)
GrantedAuthority Interface តំណាងឱ្យ Role របស់ User (ROLE_ADMIN, ROLE_BUSINESS)
UserDetailsService Interface សម្រាប់ Load User ចេញពី Database តាម Username
DaoAuthenticationProvider អ្នកផ្គូផ្គងរវាង UserDetailsService និង PasswordEncoder
SecurityFilterChain Firewall កំណត់ច្បាប់ការពារ Endpoints, Stateless Session, និង CSRF
auth.getPrincipal() ទាញយក Object User ដែលកំពុង Login ក្នុង Controller

D. កំហុសទាំង ៦ ដែលតែងតែជួបប្រទះ (Pitfalls to Avoid ⚠️):

  • ❌ Password ក្នុង Database ជា Plain text: ត្រូវតែជា BCrypt Hash (ផ្ដើមដោយ $2a$10$...)។
  • ❌ ច្រឡំ Database Password ជាមួយ Login Password: YourNewPassword123 ក្នុង application.yaml គឺជា Password របស់ PostgreSQL ទេ។
  • ❌ Method getUsername() return "": ត្រូវតែ return this.userName;។
  • ❌ ភ្លេច Prefix ROLE_: ក្នុង Role.java ត្រូវ return "ROLE_" + this.name។
  • ❌ ភ្លេច @Builder លើ UserResponse: នាំឱ្យ error cannot find symbol: method builder()។
  • ❌ ភ្លេច Restart Spring Boot: បង្កើត Controller ថ្មីរួចត្រូវ Restart ទើបស្គាល់ Endpoint (កុំឱ្យចេញ 404 Not Found)។
